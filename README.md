# 卡羅＠寫作系統

> 本網站為卡羅私人使用的學習與寫作工具。內容與功能可能隨時更改，恕不另行通知。

中文詞語練習與寫作網站：練習詞語、翻查詞卡，再用學到的詞語寫作、排版、匯出成圖片。

網址：<https://kyaroruuuu.github.io/writing_system/>

不用安裝、不用登入，用瀏覽器打開就可以；手機和電腦都適用。

## 怎樣使用

> 練習、圖鑑、房間的詞庫已加密，只供卡羅使用，需要詞庫密鑰才能打開。寫作不需要密鑰，任何人都可以使用。

### 模組

網站本身只有外框和版面，功能都是模組，每個模組是一個 `.zip` 檔：

1. 到 [Releases](https://github.com/kyaroruuuu/writing_system/releases/latest) 下載需要的模組，例如 `kyaroru-write-v….zip`（寫作）。
2. 按側欄底部的「模組」（手機在下方「更多」），選擇或拖放 .zip 檔安裝，可以一次選多個。
3. 不需要的模組可以卸下；卸下不會刪除文章或練習紀錄。

有些模組要先安裝它的前置模組：

- **寫作** → Markdown 編輯器、繁簡轉換。寫作用到 Markdown 或繁簡時，如果還沒安裝，會請你選擇那個 .zip。
- **詞庫** → 練習、圖鑑、房間。這幾個是卡羅私人使用，程式和詞語都已加密，要有詞庫密鑰才會出現在側欄。

其他說明：

- 卡羅的官方模組都有簽署，被改動過的不會安裝；其他人做的模組，安裝前會先請你確認。
- 安裝過的模組存在你的瀏覽器裏，沒有網絡也能打開網站使用。
- 有新版時「模組」旁會出現小圓點；下載新的 .zip 再安裝一次就會覆蓋舊版。
- 想自己做模組，可以看 [MODDING.md](MODDING.md)。

### 練習

1. 打開「練習」，畫面會出現一個詞語。
2. 在輸入框寫下你認為的意思，按「提交」。
3. 提交後會顯示完整釋義和例句，再按「下一個」繼續。

想直接看意思和例句，可以切換到「溫習模式」。詞語旁的喇叭可以朗讀（國語或粵語）。

### 圖鑑

瀏覽全部詞語，可按詞性、主題、情感等篩選，也可以按筆畫、字數、建立時間排序。點詞卡看完整釋義和例句。

### 房間

詞語按本意擺放在不同場景裏（客廳、廚房、書房、古城……）。點場景中的物件，就會打開對應的詞卡。

### 寫作

第一次打開時要設定一個**密語**，之後每次進入都要輸入。

- **寫作**：可選富文本或 Markdown 編輯，也可選橫書或直書；可以一鍵轉換繁簡。
- **格式**：選取文字會浮出格式列，有粗體、着重號、顏色、註腳、注音等。
- **插入詞語**：按 Ctrl＋K 從詞庫挑一個詞放進文章。
- **匯出**：按右上角「匯出」，可存成圖片（附封面、頁碼、署名、QR Code）、Markdown、HTML，或複製帶格式的文字。
- **版本紀錄**：可以比較改動，並還原到較早的版本。
- **保存**：停止打字約 10 秒會自動保存，不用手動按。
- **其他**：字數目標、休息提醒、專注模式。
- **快捷鍵**：按 Ctrl＋/ 查看全部。

### 備份

換電腦或換瀏覽器前，在「備份」頁匯出檔案，再到新瀏覽器的同一頁匯入。

## 下載版本

到 [Releases](https://github.com/kyaroruuuu/writing_system/releases/latest) 下載

- 離線版不含任何詞庫、圖片或卡羅的資料，只保留介面、格式和排版功能。
- 解壓後用瀏覽器打開 `index.html` 即可，不用上網。用雲端字體匯出圖片時才需要連線。
- 一開始詞庫是空的，可以在「詞庫」頁手動輸入詞語，或在「匯入」頁加入你自己的 Notion 匯出檔，或在「備份」頁匯入詞庫檔。
- 所有資料只存在你自己的瀏覽器裏。

## 私隱

- **寫作內容只存在你自己的裝置上**：網站不會上傳任何文字，也沒有帳戶或追蹤程式。
- **內容會加密**：寫作內容以你的密語加密保存，別人用你的瀏覽器也打不開。
- **忘記密語無法找回**：密語不會傳送到任何地方，忘記了就無法再打開舊文章。
- **定期匯出備份**：清除瀏覽器資料或用無痕模式，寫作內容會消失。重要文章請定期匯出。
- **字體下載**：匯出圖片時，網站會向 Google Fonts 下載字體檔，但不會傳送你的文章。
- **練習紀錄沒有加密**：答對答錯等紀錄只存在你的瀏覽器裏，共用電腦時請留意。
- **詞庫已加密**：詞語、釋義、例句和圖片都經過加密，沒有詞庫密鑰就無法查看。
- **錯誤回報是公開的**：「回報錯誤」會建立公開的 GitHub 議題，請不要寫入個人資料。
